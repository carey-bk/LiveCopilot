# 1.1.1 — 窗口操作与应用图标

本机安装：**1.1.1 / 20260914.191619**，位于 `~/Applications/LiveCopilot.app`。先前 1.1.0 应用已备份，现有设置、模型、知识库及 Keychain 项没有被迁移或清除。GitHub 正式 Release 仍是已发布的 1.1.0，本次没有另行发布新 Release。

## 改动

- **截图**：旧版主动对悬浮窗、设置和历史请求截图排除。现在设置和历史页允许截图；通用页提供“在截图和屏幕共享中隐藏悬浮窗”开关。默认保留悬浮窗隐藏，关闭后请求允许捕获。该选项独立于白底/毛玻璃，并持久化保存。
- **窗口大小**：四边采用 12 pt 热区，四角采用 28 × 28 pt 热区。拖动任意方向时保持对边位置，限制宽度 400–700、高度 440–1000；修正旧右下角拖动的垂直方向计算。头部按钮与底部操作留出角落空间，内容区仍能输入、选中文本。
- **Dock**：应用改为普通 macOS 激活策略，恢复 Dock 图标。点击 Dock 图标可重新显示悬浮窗，菜单栏与原有快捷键保留。
- **图标**：加入原创的“对话卡片 + 声波转文字”图标。陶瓷底座、蓝绿浮雕卡片、高光与阴影均来自可编辑 SVG；同时提供单色标志、透明 PNG 和完整尺寸的 ICNS，已接入应用。详见 [品牌资源](../assets/brand/README.md)。

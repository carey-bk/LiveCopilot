# LiveCopilot 2.8.0

## 中文

- 改善远程会议中的说话人归属，减少扬声器回声被识别成我方发言及错误打断回答。
- 保留对方插话前已识别的我方内容，改善插话时句首被截断的问题。
- 改善麦克风设备变化后的恢复与本地识别进程异常处理。
- 个性化额外提示词新增保存状态与按钮，自定义格式优先于默认回答风格。
- 精简自动回答状态文案，减少悬浮窗重复信息；默认开启回答区自动伸缩，关闭自动贴边和共享隐藏。
- 专业术语识别标记为 Beta，移到模型管理下方。热词增强效果仍因词汇与发音而异，不保证准确识别。

已有配置保留。应用与安装包使用 Developer ID 签名并通过 Apple 公证。支持 Apple Silicon 与 Intel Mac。

## English

- Improved speaker attribution in remote meetings, reducing speaker echo appearing as your speech and incorrectly interrupting answers.
- Preserved recognized speech when the other participant interrupts and improved clipped phrase beginnings.
- Improved microphone recovery after device changes and handling of local recognition worker failures.
- Added explicit saving for custom answer instructions; custom formatting takes priority over default answer style.
- Simplified answer status messages and removed repeated overlay information. Automatic answer-area sizing defaults on; edge hiding and capture exclusion default off.
- Marked terminology enhancement as Beta and moved it below model management. Recognition improvements remain dependent on vocabulary and pronunciation.

Existing settings are preserved. Developer ID signed and Apple notarized, for Apple Silicon and Intel Macs.

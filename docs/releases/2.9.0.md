# LiveCopilot 2.9.0

## 中文

- 六步新手引导帮助你选择输入方式、准备本地模型，并在开始使用前测试回答服务。自定义兼容接口支持配置服务地址和模型 ID。
- 新增「模式与场景」设置。新手引导、模式设置与实时回答触发页共用 Jev Mode 开关卡片，实时触发页还可查看 Laya 状态和调整灵敏度。
- 设置页现在明确区分知识库索引模型与回答模型。推荐在本机使用 BGE-M3 检索资料，无需 OpenAI Key。
- 知识库检索会复用已读取的向量。同一场监听中更换文档后，下一次提问即可使用更新后的资料。

## English

- Six-step onboarding guides you through audio inputs, local models and testing your answer service. Custom compatible endpoints support a configurable URL and model ID.
- Conversation modes and tools now have their own settings page. Jev Mode uses the same switch card across onboarding and settings, with Laya status and sensitivity available under real-time triggers.
- Knowledge indexing and answer generation are clearly identified in settings. The recommended local BGE-M3 index runs without an OpenAI API key.
- Knowledge retrieval reuses vectors in memory and picks up document changes during an ongoing listening session.

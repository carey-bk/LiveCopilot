# LiveCopilot 2.9.1

## 中文

- 改善长时间监听时悬浮窗的响应。连续转写和流式回答现在合并刷新，减少长回答反复排版和自动滚动造成的卡顿。
- 改进停止监听与退出时的资源回收。音频或本地推理任务响应缓慢时，应用会限制等待时间，并隔离上一场会话的延迟回调。
- 提高本地 BGE-M3 建立知识库索引的稳定性。Intel Mac 默认使用 CPU，GPU 推理失败时可回退到 CPU 重试。长文档的分段和超时处理也已改进。
- 改进故障诊断。知识库索引出错时可直接前往对应模型设置，诊断报告也能更准确地记录界面卡顿和停止监听时所处的阶段。

## English

- Improved overlay responsiveness during long listening sessions. Transcript and streaming answer updates are batched to reduce repeated layout and automatic scrolling.
- Improved cleanup when stopping or quitting. Audio and local inference tasks have bounded waits, and late callbacks from an earlier session are isolated.
- Improved local BGE-M3 indexing. Intel Macs use the CPU by default, GPU inference failures can retry on the CPU, and long documents benefit from safer chunking and revised timeouts.
- Improved diagnostics for interface stalls and session shutdown. Indexing errors now link directly to the relevant model settings.

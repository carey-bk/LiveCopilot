# LiveCopilot 2.11

## 中文

- 设置全面改版。「概览」直接告诉你能否开始监听、还差哪项设置；「模式与场景」改为选项卡片；「服务」每个标签带状态点；所有页面使用统一的卡片样式。macOS 26 起设置侧栏使用液态玻璃效果。
- 悬浮窗：监听状态合并为一行；可在提问框内选择是否附带近期对话，提问框最多可展开到六行；可设置转写展开时显示的行数；开启自动伸缩后可一直延伸到屏幕底部。背景改为四种：液态玻璃、半透磨砂、微透磨砂、纯白底色；液态玻璃需要 macOS 26，较旧的系统提供另外三种。
- 连续提问：对方补充提问时，可选择「更新当前回答」（合并后重新回答）或「另起一条回答」。后面的回答会参考前面已给出的回答。
- 回答可逐句附译文，最多可选三种语言；转写翻译开启时按钮显示为蓝色。回答末尾不再出现多余的分隔线。
- 自动回答：新增触发灵敏度滑块，分五档。对方刚问完你就开口（比如「嗯，好的」）不再取消回答；对方说话时，你说的话也会实时转写。回声判断更严格，减少把扬声器里的声音当成你说的话。
- 开始监听更快：在测试设备上，首次开始从约 7 秒缩短到 1 秒以内。
- 共享屏幕时，悬浮窗的弹出菜单和提示框也一并隐藏。使用 macOS 自带输入法时，输入法候选框也会隐藏；第三方输入法的候选框由输入法自己显示，LiveCopilot 无法隐藏。
- Apple 本地语音识别支持 31 种语言，只显示本机可用的语言。下载的语音模型重启后保持就绪。
- 从 2.9 或更早版本升级时，知识库索引迁移到 Arctic 后，会自动删除旧的 BGE 模型和旧版 Laya 运行文件，释放磁盘空间。
- 从 2.10.0 应用内更新只需下载约 3.4 MB 的增量包；增量更新失败时会自动改为下载完整安装包。
- 版本号从本版起采用「主版本.次版本」两段格式。

## English

- Redesigned Settings. Overview tells you whether listening can start and what still needs setting up. Modes & Scenarios use option cards, each Services tab shows a status dot, and every page uses the same cards. On macOS 26 and later the Settings sidebar uses Liquid Glass.
- Overlay: listening status fits on one line. Choose whether to include recent conversation inside the question field, which grows to six lines. Set how many transcript lines to show when expanded. With automatic sizing the overlay can now grow to the bottom of the screen. Four backgrounds: Liquid Glass, Frosted glass, Soft frosted and Solid white. Liquid Glass requires macOS 26; older systems offer the other three.
- Continuous questions: when the other side adds to a question, choose to update the current answer (merged and answered again) or start a separate answer. Later answers take earlier suggested answers into account.
- Answers can include sentence-by-sentence translations into up to three languages. The translate button turns blue while transcript translation is on. Answers no longer end with stray separator lines.
- Automatic answers: a five-step trigger sensitivity slider. Speaking right after a question (such as "OK, sure") no longer cancels its answer, and your speech is transcribed while the other side is still talking. A stricter echo guard is less likely to treat speaker playback as your voice.
- Faster start: on the test Mac, the first Start went from about 7 seconds to under 1 second.
- While screen sharing, the overlay's menus, popovers and tooltips are hidden too. With a built-in macOS input method its candidate window is also hidden; third-party input methods draw their own candidate window, which LiveCopilot cannot hide.
- Apple on-device speech supports 31 languages, showing only those available on this Mac. Downloaded speech models stay ready after relaunch.
- When upgrading from 2.9 or earlier, the old BGE model and old Laya runtime files are deleted automatically once the knowledge index has moved to Arctic, freeing disk space.
- In-app updates from 2.10.0 download a 3.4 MB delta instead of the full installer, falling back to the full download if the delta cannot be applied.
- Public version numbers are now MAJOR.MINOR.

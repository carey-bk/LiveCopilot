# LiveCopilot 2.12

## 中文

- 修复：回答较多时，悬浮窗可能卡死几分钟、无法点击（2.10 和 2.11 都受影响）。
- 悬浮窗的使用提示改为区域高亮：提示指向的位置保持明亮，其余区域变暗。
- 重做「关于 → 反馈问题」：选择问题类型和大约发生时间，软件会把运行日志、卡顿记录和 macOS 系统报告打包成 ZIP（每一项都能预览、也能取消），并打开一封已附上 ZIP 的邮件，你确认后发送给作者。不包含录音、对话、回答、资料或密钥。
- 软件卡住超过 3 秒时，会自动记录卡在哪里，反馈时一并打包，方便定位问题。
- 应用内更新优先连接 GitHub，连不上时自动改用香港镜像。
- 更新失败时的「官网下载页」链接，改为打开官网下载区：GitHub、百度网盘、夸克网盘。
- 本地模型去掉「复制诊断信息」按钮，自检结果会随反馈包一起提交。
- 悬浮窗的转写区显示最近 200 行，完整转写保存在历史记录中。

## English

- Fixed: with many answers, the overlay could freeze for minutes and stop responding (affected 2.10 and 2.11).
- Overlay tips now light up what they point at and dim the rest of the window.
- Redesigned About → Report a problem: choose what happened and roughly when, and LiveCopilot packs the app log, freeze records and macOS system reports into a ZIP (each part can be previewed or left out), then opens an email to the author with the ZIP attached for you to send. No audio, conversation, answers, documents or keys are included.
- When the app stops responding for more than 3 seconds, it records where it was stuck, and the record goes into the feedback ZIP.
- In-app updates try GitHub first and switch to a Hong Kong mirror when GitHub cannot be reached.
- When an update fails, the download page link opens the website's download section: GitHub, Baidu Netdisk and Quark Netdisk.
- Local models no longer have a Copy diagnostics button; self-check results go into the feedback ZIP.
- The overlay transcript shows the latest 200 lines; the full transcript is kept in History.

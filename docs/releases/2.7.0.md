# LiveCopilot 2.7

- 转写区支持三行折叠，原文与译文统一对齐；折叠时自动跟随最新内容。
- 新增转写翻译及目标语言选择，支持稳定临时转写和流式译文。
- Zipformer 英文大小写整理，改善英文转写可读性。
- 自由知识、混合知识、仅知识库三种回答模式；混合模式对无关问题使用通用知识。
- 自动回答显示具体等待或拦截原因，诊断包含阶段计数与最近事件。
- 修复部分因我方语音被抑制的问题，在新转写事件到达后无法重新判断的情况；保留防抢答与旧事件去重。
- 新增本地诊断摘要和私下反馈 ZIP，可选择包含原始崩溃报告；不会自动上传。
- 改善音频故障记录、反馈输入框与导出流程，保留已有设置、模型、凭证和历史。

转写翻译使用已配置的回答服务，可能产生服务费用。诊断不保证自动定位所有故障；请附发生时间和复现步骤。Laya 模型权重未更新。

## English

- Compact three-line transcripts with consistent original/translation alignment.
- Optional streaming transcript translation and Zipformer English casing cleanup.
- General, mixed and knowledge-base-only answer modes, with improved mixed-mode instructions.
- Explicit automatic-answer gate status, diagnostic counters and bounded event history.
- Allow a fresh final transcript event to retry a question previously suppressed by own speech while preserving stale-event and duplicate protection.
- Local diagnostic summaries and private support ZIP export, optional raw crash reports, and clearer export controls. Nothing is uploaded automatically.
- Existing settings, credentials, models and history are preserved. Translation may incur configured provider charges; Laya model weights are unchanged.

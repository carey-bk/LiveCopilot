# Phase 4 / 4.1 3D Hero archive

This folder preserves the September 2026 Three.js/CSS3DRenderer Hero experiment.
Phase 5 removed it from the production website in favor of a static MacBook hardware composition with the live DOM product preview.

These files are intentionally excluded from `StealthApp/scripts/build-site.py` and are not published to `_site/`.

The separate Phase 4 hardware prototype was also backed up locally under
`dist/website-backups/phase4-prototype-source-20260921.tar.gz` and
`dist/website-backups/phase4-prototype-reference/`. Its supplied license record
permits local prototype use only, so these assets are not committed or published.
The original adjacent Git worktree is retained for recovery, not a build input.
